# Workbook-backed operating research report

The shared U.S. operating exporter reads the recalculated Excel cells for every modeled figure, segment label, forecast, scenario value and price diagnostic. The Report Evidence sheet stores the dates, text and links for retained SEC Business and Risk Factors excerpts, event filings and earnings releases. Open a source reference in the PDF to read the filing. The excerpt date identifies the filing or release date.

The live writer receives a JSON fact sheet and selects and orders three distinct thesis sentences from a bounded set. Workbook values are formatted by code. The supporting sections render directly from workbook facts and source passages. Archived and offline runs use a deterministic thesis order, so replay needs no provider. Unsupported facts remain visibly unavailable.

The PDF audit reconstructs the approved report from the supplied workbook. It compares the full extracted text in order after whitespace and Unicode normalization. Numeric values and percentages must match their displayed rounding in context. Exact workbook names must appear on the forecast lines. The PDF source links and workbook SHA-256 are checked as well. Editing a number to a value present in another cell still fails if that value is wrong for the labeled claim.

The deliberate corruption regression stamps a spurious revenue figure onto the rendered PDF and expects the audit to reject the download. The general operating pair checker invokes the same audit independently. The legacy Apple exporter still handles its dedicated model.
